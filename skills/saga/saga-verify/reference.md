# /saga-verify — reference

## TRACEABILITY.md format

```markdown
# Traceability: <project> — Milestone <vX.Y>

Generated by /saga-verify on <date>. Source of claims: .planning/REQUIREMENTS.md.

| REQ-ID | Status | Evidence | Notes |
|--------|--------|----------|-------|
| ACCESS-01 | PROVEN | `tests/test_router_access.py::test_key_perms` (5/5) | |
| ACCESS-02 | PROVEN | commit `a1b2c3d`; live `ssh router '/ip/route/print'` capture | |
| INSPECT-01 | OPEN | — | not yet implemented |
| INSPECT-03 | ASSERTED | none located | **checkbox [x] but no evidence — verify or unmark** |
| SAFE-21 | PROVEN | `decisions/0007-no-route-mutation.md`; grep: zero route-write calls | cross-cutting invariant |
| OBSERVE-02 | WAIVED | `decisions/0009-defer-dry-run-rerun.md` | accepted gap, operator-signed |

## Gaps (action list)
- **ASSERTED (claimed, unproven):** INSPECT-03
- **OPEN (not done):** INSPECT-01
```

## Where to look for evidence
- `tests/` — a passing test whose name/assertion maps to the REQ.
- Git — a commit SHA / message referencing the REQ-ID (`git log --oneline --grep=<REQ-ID>`).
- `.planning/decisions/*.md` — a waiver accepting a gap → WAIVED (link it).
- `.planning/**/–VERIFICATION.md`, `*-SUMMARY.md` frontmatter — legacy proof artifacts (valid evidence).
- Live-output captures (`.planning/**/evidence/*.json|md`), runbook command output.

## Classification rules
- **Evidence must be a concrete artifact**, not a paraphrase of the requirement. "Implemented X" is not evidence;
  a test, SHA, or captured output is.
- A checked box (`[x]`) with no locatable artifact is **ASSERTED**, not PROVEN — this is the whole point of the skill.
- A `SAFE-NN` "no mutation" invariant is PROVEN by evidence of *absence* (grep showing zero write calls + a
  decision record), not just a claim.
- This is a cross-reference of *claim (REQUIREMENTS) vs proof (evidence)*.
